Inside TaxPower TDS

Built around your return workflow.

From deductor records to return review and TRACES activity — explore the screens that bring your daily TDS work together.

DeductorsReturnsRegisterComplianceTRACES
01 Deductors Dashboard

Your deductors. One organised workspace.

Find the right deductor, review key details and move into return preparation from a single TaxPower TDS dashboard.

  • Search, group and sort deductors
  • View TAN, PAN, deductor type and state
  • Add, import and export deductor records
02 Returns Dashboard

Every return, clearly in view.

Review regular and correction returns by financial year, quarter and form. Keep filing details close at hand.

  • Filter returns by form and financial year
  • Track filing dates, due dates and status
  • View token numbers and revision history
03 Return Register

A wider view of your returns.

Bring your return records together in the TaxPower TDS Return Register for a clear view across your filing work.

  • Filter by group, period, form and return type
  • Track filing, processing and certificate status
  • Get return status and export the register
04 Computation & Compliance

Check the numbers. Review the exceptions.

See tax, interest and fees alongside PAN, challan and deduction checks before taking the next step in your return workflow.

  • Review tax payable and challan utilisation
  • Check invalid or inoperative PANs
  • Identify challan mismatches and deduction differences
  • Review interest, late fees and missing salary details
05 TRACES Activity

TRACES requests, without losing track.

Request files, check availability and follow downloads from the return itself. Keep supporting documents close to the work they belong to.

  • Request and download Conso files
  • Track certificate requests and downloads
  • Access Justification Reports
  • Check request status and open downloaded files
